「网哨 (NetSentinel)」轻量级网络资产监控系统 —— 技术白皮书 v1.0
1. 项目概述 (Executive Summary)
随着企业信息化建设的深入，网络设备及服务器节点数量激增。「网哨 (NetSentinel)」专为百节点规模的企业网络设计，提供开箱即用、极简轻量、实时可视的网络存活状态监控方案。系统摒弃了传统重型监控框架（如 Zabbix）的臃肿，以纯 Docker 容器化方案交付，实现零侵入式部署、大屏实时可视、以及智能化的飞书告警与周报推送。

2. 系统架构设计 (Architecture Design)
本系统采用轻量化 B/S 架构，前后端分离，核心基于 Python 异步生态构建。

运行环境： 纯 Docker 容器化运行，依赖极简。

后端 API 与核心引擎： Python 3.10+ + FastAPI。利用原生 Asyncio 协程实现高并发网络探测。

数据持久层： SQLite3。单文件存储，挂载宿主机 Volume 保证数据安全，免去独立数据库维护成本。

前端大屏展示： HTML5 + Vue 3 (CDN) + TailwindCSS (CDN)。无需编译，浏览器原生解析，实现数据响应式双向绑定。

3. 核心功能特性 (Core Capabilities)
3.1 毫秒级并发探测引擎
依托 Python 协程池，单节点可轻松承担 500+ IP 的并发 ICMP 探测任务。探测周期支持动态调整，默认 30 秒一轮，兼顾实时性与系统开销。

3.2 智能防抖与风暴抑制 (Alert Smart-Routing)
状态跃迁防抖： 引入容忍度机制（如连续 3 次 Ping 失败），过滤微小网络波动引起的假报警。

告警风暴合并： 采用 5 秒缓冲池技术，当核心设备宕机引发雪崩效应时，系统自动将数十条告警合并为一条“大面积网络波动”卡片，防止飞书接口限流。

3.3 NOC 级大屏可视 (Glanceability UI)
免登录看板： 专为大屏幕投放设计，支持深色模式。

动态优先级渲染： 告警设备自动强制置顶展示，辅以高饱和度红色及呼吸灯特效，“一瞥即知”全网健康度。

3.4 自动化闭环运维
无状态鉴权： 后台管理接口采用 JWT Token 保护，管理员凭证通过 Docker 环境变量安全注入。

SLA 自动化周报： 内置 APScheduler 定时任务，每周五 17:00 自动拉取数据库日志，生成本周网络质量 SLA 报表、Top 3 故障节点，并推送至飞书群，形成管理闭环。
