# P3：1000 目标模拟探测复测

执行环境：macOS（Darwin）、Python 3.12、SQLite WAL。项目、虚拟环境、测试数据和临时文件均位于外挂盘。探测函数以立即成功的 mock 代替网络请求；1000 个目标通过批量 API 导入，再触发一轮监控。测试独立运行，未与 pytest 并发。

| 指标 | P1 | P3 |
| --- | ---: | ---: |
| 目标数 / 完成探测数 / 在线数 | 1000 / 1000 / 1000 | 1000 / 1000 / 1000 |
| 单轮墙钟时间 | 0.728 秒 | 0.739 秒 |
| 引擎统计耗时 | 0.720 秒 | 0.704 秒 |
| 数据库主文件与 WAL | 5,214,192 字节 | 5,226,288 字节 |
| 峰值 RSS | 109,772,800 字节 | 123,895,808 字节 |

执行命令：`python scripts/benchmark_1000.py`。这是一轮模拟探测，能验证状态写入和调度没有明显变慢；它不能代表真实网络延迟、长期数据库增长或生产内存上限。P3 模型与迁移增加了约 12 KiB 数据库空间，峰值 RSS 比 P1 高约 13.5 MiB；后续持续压测应关注内存。
