# P1：1000 台目标模拟探测压测

执行环境：macOS（Darwin），Python 3.12，SQLite WAL；全部数据和临时文件位于外挂盘。探测函数以立即成功的 mock 代替网络请求，1000 台设备通过批量 API 导入后触发单轮探测。

| 指标 | 实测 |
| --- | ---: |
| 设备数 / 完成探测数 / 确认在线数 | 1000 / 1000 / 1000 |
| 单轮墙钟时间 | 0.728 秒 |
| 监控引擎统计耗时 | 0.720 秒 |
| 数据库主文件与 WAL 合计 | 5,214,192 字节（约 4.97 MiB） |
| 进程峰值 RSS | 109,772,800 字节（约 104.7 MiB） |

执行命令：`python scripts/benchmark_1000.py`。脚本在仓库内创建外挂盘临时目录，退出时删除。

本测试评估状态写入与调度开销，不能代表 1000 台真实 ICMP/TCP/HTTP 设备的网络耗时、渠道投递耗时或长期数据库增长。长期容量由探测周期、保留天数和告警频率决定，需要另行测量。
