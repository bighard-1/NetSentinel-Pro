# Security policy

## Supported versions

Security fixes are developed for the latest release. Older releases may require upgrading first.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/bighard-1/NetSentinel-Pro/security/advisories/new) when it is enabled for this repository. If it is unavailable, open an issue requesting a private contact channel without posting exploit steps, credentials, or affected system details.

Include the affected version, impact, reproduction steps, and a suggested fix when possible. Do not send real passwords, tokens, Webhook URLs, or production database backups.

The maintainer will acknowledge the report and coordinate disclosure after a fix is available. No fixed response-time commitment is made for this personal project.
